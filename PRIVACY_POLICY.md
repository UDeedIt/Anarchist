# Privacy Policy for Anarchist Library Demo

Effective Date: July 27, 2026

This Privacy Policy describes how the Anarchist Library Demo ("the App"), developed by UDeedIt Pro, handles data and permissions. The App is a professional demonstration utility for the Anarchist Android Library, designed to showcase simplified, reactive, and unified permission management.

## 1. Zero Data Collection Policy
Anarchist is built on a "Privacy-First" architecture. We do not collect, transmit, or store any user data on external servers. All permission requests and state checks are performed locally on the host device.

## 2. Permission Request Rationale
The App serves as a live environment to test the library's ability to handle various Android system permissions. As such:
*   Demonstration Requests: The App will request various permissions (e.g., Notifications, Alarms, etc.) exclusively to demonstrate the library's "Allow them all" logic.

* No Data Access: Even when a permission is granted for demonstration, the App does not access, read, or export the associated user data (such as contacts, files, or location).

* Local State Only: The library only tracks the status of the permission (Granted, Denied, or Rationale needed) to update the UI reactively.

## 3. Third-Party Integration
This App is a pure utility. It does not contain third-party tracking, advertising, or analytics SDKs. No information regarding your device or permission states is shared with third-party service providers.

## 4. Permission Transparency
As an "Anarchist" tool, we believe in giving the power back to the developer and the user. Every permission requested by this demo can be revoked at any time via system settings without affecting the App's stability.

## 5. Data Deletion
All local states and demonstration settings are scoped to the application. Stored values and permission metadata are permanently purged by the Android system upon uninstallation of the App.

## 6. Commitment to Developers
As a D2D (Developer-to-Developer) product, we are committed to transparency. The logic demonstrated in this app is identical to the open-source logic provided in the official Anarchist library distribution.
