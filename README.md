# Anarchist 🏴‍☠️

Android Permissions Library — Allow them all!

Anarchist is a developer-centric (D2D) library designed to liberate your code from the boilerplate of Android permission handling. It provides a clean, reactive, and unified way to request, check, and manage permission states.

---

## 🚀 Why Anarchist?
Managing permissions on Android has become increasingly complex across different API levels. Anarchist breaks this complexity by providing:
- Boilerplate Freedom: Request permissions without messy Activity Results logic.
- Reactive States: Observe permission status changes in real-time.
- Special Permissions support: Simplified handling for Notifications, Exact Alarms, and more.
